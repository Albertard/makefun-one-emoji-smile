# One Emoji, One Smile

> 🥹

One emoji, nothing else: 🥹 — a face holding back happy tears, eyes shining, a small tender smile. It is the warmest single face in the set: it reads instantly as gratitude, affection and quiet joy, the kind of expression that makes a stranger smile back without a word being said. No caption, no explanation — the feeling is the whole entry.

## How to run

Requires Node.js 22 or later. No dependencies — standard library only.

```sh
node main.ts
```

This writes the entry emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`), creating the directory if needed. The output has no trailing newline. Before writing, the script checks that the entry is 1–8 Unicode code points, a single line, and not whitespace-only, and throws otherwise.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/emoji-out node main.ts
```
